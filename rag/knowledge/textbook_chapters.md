## 3.1 大 O 表示法

大 O 表示法描述的是算法运行时间的**上界**，而不是精确运行时间。对于函数 f(n)，若存在常数 c > 0 和 n0，使得对所有 n ≥ n0 都有 0 ≤ f(n) ≤ c·g(n)，则称 f(n) = O(g(n))。

## 3.2 常见时间复杂度等级

按增长速度从低到高：O(1) < O(log n) < O(n) < O(n log n) < O(n^2) < O(2^n)。

## 3.3 时间复杂度分析示例

- 单层循环：O(n)
- 双层嵌套循环：O(n^2)
- 二分查找 / 平衡树：O(log n)
- 分治（归并排序、快速排序平均）：O(n log n)

## 3.4 最坏 / 平均 / 最好情况

分析复杂度时必须注明是最坏、平均还是最好情况。快速排序最坏 O(n^2)（输入有序且枢轴选择不当），平均 O(n log n)。

## 3.5 空间复杂度

空间复杂度分析算法额外占用的内存。原地算法 O(1) 额外空间；递归栈深度也计入空间复杂度。
